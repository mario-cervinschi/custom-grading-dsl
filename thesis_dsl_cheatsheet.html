Category Keyword / Token Usage Example
Iteration APPLY TO Apply a lambda transformation to a list of variables. APPLY x => x / 2 TO lab1, lab2;
Iteration LOP => Lambda separator — binds the parameter to its body in an APPLY expression. APPLY grade => grade * 0.8 TO exam;
Conditional WHEN EXISTS Guard: executes the following statement only if all listed variables are present in the data row. WHEN lab1, lab2 EXISTS EXPLAIN bonus = lab1 + lab2;
Conditional ASK ? COLON : Ternary (inline if-else) operator — condition ? then : else. score > 50 ? "pass" : "fail"
Conditional IN [ ] Membership test — checks whether an identifier's value matches one of the listed constants. status IN [absent, excused] ? 0 : lab1
Annotation EXPLAIN Marks a statement for explanation output: records the original expression, substituted values, and result. EXPLAIN final = exam * 0.6 + lab * 0.4;
Annotation EXPLAIN … , STRING Attaches a human-readable description to an explanation entry. EXPLAIN final = exam * 0.6, "Weighted exam score";
Assignment ASSIGN = Assigns the result of an expression to an identifier in the evaluation memory. bonus = lab1 + lab2;
Arithmetic ADD +  SUB -  MUL *  DIV / Standard arithmetic operators; respect operator precedence (* / / before + / -). avg = (lab1 + lab2) / 2;
Comparison EQ == NE != GT > GE >= LT < LE <= Relational operators; produce a boolean result used in conditionals. exam >= 50 ? "pass" : "fail"
Logical AND &&  OR ||  NOT ! Boolean connectives; AND binds tighter than OR; NOT is a unary prefix. lab1 > 0 && lab2 > 0 ? avg : 0
Regex Match MA ~  NM !~ Pattern match (~) and negative match (!~) against a string literal. comment ~ "^ok.*" ? 10 : 0
Built-in Function MAX Returns the maximum of its arguments. top = MAX(lab1, lab2, lab3);
Built-in Function MIN Returns the minimum of its arguments. floor = MIN(exam, 100);
Built-in Function ROUND Rounds a numeric expression to the nearest integer. final = ROUND(avg * 1.1);
Status Constant absent present excused Attendance-related sentinel values for a student record field. att IN [absent, excused] ? 0 : lab1
Status Constant nothing ungraded toolow Grade-state sentinels indicating a missing, unprocessed, or below-threshold result. lab1 == nothing ? 0 : lab1
Status Constant fraud cancelled invalid alert conflict obscured Integrity-related sentinels flagging anomalous submission states. sub IN [fraud, cancelled] ? 0 : score
Literal INT  FLOAT Numeric literals; FLOAT requires a decimal point. scaled = lab1 * 0.75 + 5;
Literal STRING Double-quoted text; used as regex patterns or description annotations. EXPLAIN r = exam, "Final examination result";
Literal IDENTIFIER Variable name — references a field from the student data row or a previously computed value. final = exam * 0.6 + bonus;
Punctuation SEMICOLON ; Statement terminator — required at the end of every top-level statement. avg = (lab1 + lab2) / 2;
Punctuation COMMA , Separates items in variable lists, argument lists, or the optional description in EXPLAIN. APPLY x => x * 2 TO lab1, lab2, lab3;
Punctuation LPAREN (  RPAREN ) Groups sub-expressions or wraps function arguments. r = ROUND((a + b) / 2);
Punctuation LBRACK [  RBRACK ] Encloses a constant list in an IN membership test. s IN [absent, fraud] ? 0 : score
